Security & disclosure

This site should practice what it teaches. Here is how it is built, what the hardened build adds and how to report a problem.

Built-in protections

  • No cookies or analytics. The only third-party request is Google Fonts, plus your own Worker if live VirusTotal results are switched on.
  • Pasted messages, headers and file names are inserted as text, never as HTML, which blocks script injection.
  • Files are hashed in the browser with Web Crypto. Only the hash is ever looked up.
  • Generated passwords come from the browser’s cryptographic random source.
  • The VirusTotal API key lives in a Worker, never in page code.
  • External links open with noopener.

Hardened build

The self-hosted version ships these response headers. harden.py recomputes the script hashes after every edit.

Responsible disclosure

Found a vulnerability? Email security@example.com with steps to reproduce it. Please keep testing to your own data and accounts, avoid denial-of-service and social engineering, and give us reasonable time to fix before sharing details. Good-faith research is welcome, and reports are acknowledged within five business days.
