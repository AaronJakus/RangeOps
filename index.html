    Password rules to live by

    • Use 14+ characters; longer beats complex.
    • Never reuse a password between accounts.
    • Store them in a reputable password manager.
    • Turn on multi-factor authentication wherever offered.
    • Change a password immediately if a breach is suspected.

    Security tools

    Working tools, not just lessons. The checks run in your browser and nothing you paste is uploaded.

    Spam & phishing checker

    Paste a message and get a risk score with the exact rules that fired.

    VirusTotal lookup

    Look up a URL, domain, IP address or file hash. For a file, drop it below: it is hashed locally and never uploaded.

    Reports open on virustotal.com. A hash VirusTotal hasn’t seen is not proof that a file is safe.

    Email header analyzer

    Paste a message’s full headers (in Gmail: ⋮ → Show original). It checks SPF, DKIM and DMARC, compares sender domains and traces the delivery path.

    Security & disclosure

    This site should practice what it teaches. Here is how it is built, what the hardened build adds and how to report a problem.

    Built-in protections

    • No cookies or analytics. The only third-party request is Google Fonts, plus your own Worker if live VirusTotal results are switched on.
    • Pasted messages, headers and file names are inserted as text, never as HTML, which blocks script injection.
    • Files are hashed in the browser with Web Crypto. Only the hash is ever looked up.
    • Generated passwords come from the browser’s cryptographic random source.
    • The VirusTotal API key lives in a Worker, never in page code.
    • External links open with noopener.

    Hardened build

    The self-hosted version ships these response headers. harden.py recomputes the script hashes after every edit.

    Responsible disclosure

    Found a vulnerability? Email security@example.com with steps to reproduce it. Please keep testing to your own data and accounts, avoid denial-of-service and social engineering, and give us reasonable time to fix before sharing details. Good-faith research is welcome, and reports are acknowledged within five business days.

    Learn & respond

    Know what to do, know the terms, know where to look.

    If you think you've been hacked

    1. Disconnect the device from the network.
    2. Change passwords from a different, clean device, starting with email.
    3. Turn on multi-factor authentication.
    4. Tell your IT contact or manager right away.
    5. Watch bank and account activity, and report fraud if needed.
    Report an incident

    Safe browsing basics

    • Check for HTTPS, but remember it doesn't prove a site is trustworthy.
    • Avoid sensitive tasks on public Wi-Fi, or use a trusted VPN.
    • Download software only from official sources.
    • Don't reuse passwords on unfamiliar sites.

    Glossary

    MFA
    A second proof of identity, like a code or app prompt, besides your password.
    Phishing
    Fake messages designed to trick you into giving up information or clicking.
    Ransomware
    Malware that locks your files and demands payment.
    Social engineering
    Manipulating people rather than computers to gain access.
    VPN
    A service that encrypts your internet traffic.
    Password manager
    An app that stores unique passwords securely.

    FAQ

    Are password managers safe?

    Reputable ones encrypt your vault and are far safer than reusing passwords.

    How often should I change passwords?

    Change them when there's a breach or suspicion, not on a fixed schedule, if they're long and unique.

    Is SMS MFA good enough?

    It's better than nothing, but an authenticator app or security key is stronger.
